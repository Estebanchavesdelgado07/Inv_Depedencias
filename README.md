# Inv_Depedencias
El principio de Inversion de Dependencias dice que, una clase de alto nivel, no puede depender de clases de bajo nivel, ademas, es necesario que las abstracciones no dependan de los detalles, si no, que los detalles dependan de las abstracciones. En el codigo se muestra con la clase admProducto, que cuando necesita mandar un recibo de compra, no hace falta que contenga las clases de EnviarEmail o EnviarApp dentro de su codigo, haciendolo independiente de estas clases. Por el lado de las abstracciones, la clae de admProductos no sabe que existen las clases EnviarEmail y EnviarApp, solo sabe que existe una abstraccion llamada EnviarRecibo que tiene la capacidad de enviar recibos. Por ultimo, el main decide como se va a enviar el recibo.
